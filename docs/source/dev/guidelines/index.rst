==========
Guidelines
==========

The five authoritative references that govern the KPF-DRP vNext project, in
strict precedence order -- when they conflict, the higher one wins:

#. **WMKO technical requirements** -- the W. M. Keck Observatory's binding
   technical requirements for the DRP (highest authority).
#. **EPRV data standard** -- the source of truth for KPF's L2/L4 data products
   (FITS structure, keyword names, units, reference frames).
#. **KPF-DRP vNext charter** -- project intent, scope, scientific focus, and
   design principles.
#. **KPF-DRP vNext architecture** -- the pipeline's structure (data-model
   hierarchy, header standardization, CLI/module layering, masters pipeline,
   diagnostics/QC/checkpoint layers).
#. **KPF-DRP vNext style guide** -- code conventions (formatting, naming,
   docstrings, error handling).
