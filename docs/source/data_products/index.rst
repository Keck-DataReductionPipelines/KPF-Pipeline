=============
Data Products
=============

Reference for the FITS files the KPF-DRP vNext writes: the extensions on each
data level, the header keywords they carry, and the provenance extensions that
record how a file was produced. Content to follow.

The extension and keyword tables on these pages are generated at build time
from ``kpfpipe/data_models/config/``, the same source of truth the pipeline's
extension manifest and keyword registry read at runtime.
